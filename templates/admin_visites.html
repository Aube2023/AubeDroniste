Ce sont des pages vues, pas des visiteurs uniques : le site ne pose aucun cookie de mesure et ne garde aucune adresse IP, donc deux visites ne peuvent pas être rattachées à la même personne. Le pays est résolu sur le serveur puis oublié ; seul le compteur reste.

D'où viennent ces chiffres : le serveur lui-même compte chaque page HTML qu'il sert (aucun script de mesure, aucun service tiers). Les robots sont comptés à part : ceux qui se nomment (Googlebot, GPTBot, Semrush…) et ceux qui se font passer pour Chrome mais n'envoient pas ce qu'un vrai navigateur envoie toujours avec une page (langue, type de contenu demandé, en-têtes de navigation). Avant le 14 septembre 2026, ces derniers passaient pour des visiteurs : les journées précédentes sont gonflées.
