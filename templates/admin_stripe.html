Ce qui reste à faire
  1. {{ yn(d.connect) }} Connect actif sur le compte plateforme, en mode réel : dashboard.stripe.com/connect → Commencer → comptes Express, profil de plateforme rempli. Tant que c'est « non », l'inscription Stripe d'un pilote échoue (« You can only create new accounts if you've signed up for Connect »). Si un autre compte Stripe du même propriétaire a déjà Connect, c'est lui qu'il faut brancher (étape 2).
  2. {{ yn(d.connect_flag and d.webhook_secret and not d.account_mismatch) }} Brancher les clés du bon compte : sur le serveur, sudo bash /srv/aubepilot/deploy/go-live-stripe.sh. Le script demande la clé secrète et la clé publiable (Développeurs → Clés API, mode réel), vérifie à l'API que le compte répond et que Connect est ouvert, crée lui-même les deux webhooks (paiements et Connect), écrit les variables (dont STRIPE_CONNECT_ENABLED=1 et STRIPE_ACCOUNT_ID) et redémarre. Aucune clé ne passe par un courriel ni un chat.
  3. Facultatif : Connect → Paramètres → Cross-border payouts, pour payer des pilotes hors {{ platform_country }}.
  4. Si une ancienne clé secrète a circulé : la révoquer dans le dashboard de l'ancien compte (Développeurs → Clés API), et y supprimer le webhook devenu inutile.
  5. Test réel à petit montant : un pilote fait son onboarding, un client réserve, valide la livraison, et le virement apparaît sur le compte connecté. Cette page doit alors afficher le compte pilote et les deux webhooks « le nôtre » sans évènement manquant.
