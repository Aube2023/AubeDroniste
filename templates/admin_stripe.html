Ce qui reste à faire
  1. {{ yn(d.connect) }} Activer Connect sur ce compte, en mode réel : dashboard.stripe.com/connect → Commencer → comptes Express, remplir le profil de plateforme. Tant que c'est « non », l'inscription Stripe d'un pilote échoue (« You can only create new accounts if you've signed up for Connect »).
  2. Facultatif : Connect → Paramètres → Cross-border payouts, pour payer des pilotes hors {{ platform_country }}.
  3. {{ yn(d.connect_flag) }} Basculer l'app : sur le serveur, STRIPE_CONNECT_ENABLED=1 dans /etc/aubepilot.env puis systemctl restart aubepilot. L'onboarding Stripe réapparaît dans l'espace pilote ; « paiement en direct » disparaît.
  4. Rouler la clé secrète si elle a circulé (dashboard → Développeurs → Clés API → Rouler), la coller dans /etc/aubepilot.env sur le serveur, jamais dans un courriel ni un chat, puis redémarrer. Cette page confirme que la nouvelle clé répond.
  5. Test réel à petit montant : un pilote fait son onboarding, un client réserve, valide la livraison, et le virement apparaît sur le compte connecté.
